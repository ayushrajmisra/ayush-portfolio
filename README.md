## Overview

This repository contains the source code of my personal portfolio website.

The portfolio represents my work at the intersection of technology, entrepreneurship, product development and community leadership.

It introduces my experience, projects, skills, education and professional activities through a modern web experience.

## Key Features

- Modern and responsive user interface
- Professional introduction and profile
- Projects and product showcase
- Professional experience and education
- Technical skills and technology stack
- Leadership and community impact
- Contact and social media integration
- SEO and search engine discoverability
- AI-readable information through `llms.txt`
- Dedicated About, Contact and Terms pages
- Custom Open Graph social sharing metadata

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/ayushrajmisra/ayush-portfolio.git
```

Navigate into the project:

```bash
cd ayush-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

The production-ready files are generated in the `dist/` directory.
